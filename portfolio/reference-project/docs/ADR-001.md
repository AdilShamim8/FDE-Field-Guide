# ADR 001: Hybrid Search and Deterministic Citation Verification for ETISE

## Status
Accepted

## Date
2026-09-18

## Context
The customer needs an automated triage and response assistance service for 12,000 daily tickets. A central risk identified by customer compliance leadership is model hallucination: if the system fabricates an SLA refund policy or cites a non-existent clause, the enterprise faces contractual penalties. In addition, port and regulatory codes contain precise alphanumeric identifiers (e.g. "Section 4.1.9-B") that standard dense vector embeddings frequently fail to retrieve due to tokenization fragmentation.

## Decision
We made two foundational architectural decisions:

1. Hybrid retrieval: combine BM25 sparse keyword indexing with dense vector embeddings. Sparse search guarantees exact alphanumeric code retrieval, while dense embeddings capture conceptual semantic similarity.
2. Deterministic citation verification: rather than relying on the LLM to accurately declare whether its answer is grounded, the application layer programmatically validates that every quotation and cited policy section in the generated answer exists verbatim within the retrieved source chunks. If quotation verification fails, the system refuses to emit the draft and routes the ticket to the human review queue.

## Consequences

### Positive
- Zero ungrounded citations: ungrounded claims are blocked deterministically before reaching support agents.
- High recall on exact codes: operators searching for exact policy identifiers receive 100% precision on keyword queries.
- Operational simplicity: the system runs without requiring expensive external vector database clusters during pilot phases.

### Negative
- Higher generation latency: verifying citations adds approximately 40ms to 80ms of deterministic text parsing time.
- Conservative refusal rate: borderline answers where the model paraphrases accurately but fails verbatim quotation are routed to the human queue, slightly increasing initial reviewer volume.
