DATA NOTE / CFPB METADATA

A small, traceable start.

The foundation exercise uses five actual complaint metadata records to teach counting, SQL, and repeat imports.

  • Received and captured on October 9, 2026
  • One selected product category; no narratives
  • An ingestion sample, without triage quality labels
Inspect the retained input ↗
The exact October 11 query returned zero records at capture time. The retained sample keeps its original dates.
BUILD NOTE / LOCAL REFERENCE

Inspect how the system behaves.

Use the ETISE ticket API to practice request validation, replay, policy retrieval, and routing to human review.

  • Deterministic rules and authored sample policies
  • Caller-supplied roles for local simulation
  • Known regression checks, separate from real-data evaluation
Run and understand the reference ↗
The reference has no model calls, authenticated tenant identity, or durable dispatch. The expert route covers the work still needed.
