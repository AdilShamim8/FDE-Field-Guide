# AI and LLM Engineering

The AI-specific engineering an FDE needs. Most FDE hires in 2025-2026 are deploying LLM
systems into enterprise environments, so this section covers the patterns, the evaluation
discipline, and the operations that make probabilistic software production-grade.

- [LLM application patterns](01-llm-application-patterns.md) - extraction, RAG, structured output, context engineering
- [Agents and tools](02-agents-and-tools.md) - tool calling, agent loops, MCP, and when not to use agents
- [Evaluation and testing](03-evaluation-and-testing.md) - proving quality to a skeptical customer
- [Monitoring and reliability](04-monitoring-and-reliability.md) - operating systems whose behavior is probabilistic

Evaluation is the single most transferable AI skill for FDEs. If you only master one
document here, make it [evaluation and testing](03-evaluation-and-testing.md).
